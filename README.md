📖 About The Project
Organic Store is a full-stack e-commerce web application that allows users to browse, search, and purchase organic products online. The platform includes user authentication, product management, shopping cart functionality, and an admin dashboard for managing products and orders.

The project is built using server-side rendering with EJS and follows MVC architecture using Node.js, Express, and MongoDB.

---

✨ Features

🔐 Authentication & Authorization
- User Registration & Login
- Session-based Authentication
- Secure Password Handling

🛍️ Product Management
- Browse Organic Products
- Product Categories & Filtering
- Product Detail Pages

🧺 Shopping Cart
- Add / Remove Products
- Cart Quantity Management
- Checkout Flow

📦 Order Management
- Place Orders
- View Order History
- Order Tracking (if implemented)

🛡️ Admin Panel
- Add New Products
- Edit Existing Products
- Delete Products
- Manage Orders & Users

🚀 Getting Started

Clone the Repository

git clone <your-repo-link>
cd organic-store

Install Dependencies

npm install

Create Environment Variables

PORT=3000
MONGODB_URI=your_mongodb_connection_string
SESSION_SECRET=your_secret_key

Run the Application

npm start

or

npm run dev
